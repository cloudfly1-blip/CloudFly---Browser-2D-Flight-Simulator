## ✈️ About CloudFly

CloudFly is a flight simulation project built around one simple idea: making the experience of flying accessible through a web browser.

Instead of requiring players to download a large game package, CloudFly runs online using browser technologies. This makes it possible to access the game through a supported web browser on compatible devices.

The project focuses on the excitement of aviation, aircraft movement, and the experience of taking control of a plane in a virtual environment.

CloudFly is an evolving project. New ideas, improvements, and features can be introduced as development continues.

## 🌍 Play Anywhere

CloudFly is designed to be accessed online through a web browser.

Depending on browser compatibility and device performance, players may be able to open the game on:

- 💻 Windows computers
- 🍎 macOS computers
- 📱 iPhones
- 📱 iPads
- 🤖 Android phones and tablets

No separate game download is required for the hosted browser version.

**Note:** Performance and compatibility can vary between devices and browsers. Not every browser is guaranteed to work correctly.
